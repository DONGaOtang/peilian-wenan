# 对话引导手册（P3 参考文件）

> P3 的本质：把内容主体从 AI 搬回用户。AI 瞎写的根源是内容主体错位——AI 当作者就只能编。
> 用户说出来的东西自带真实素材和指纹，AI 只做拆解和排布。

## 基本规则

1. **最多三轮关键问题**：观点 / 亲身经历 / 想让观众看完干嘛。多一轮都是摩擦
2. **每轮给结构选项 + 自由输入**：用户可以选提示的选项，也可以自己说，口语即可，不用组织语言
3. **失效预案（宪法级）**：用户答不出/说「我也没啥想法」→ 换话题回 P2，绝不硬写。对话是挖矿，挖不到矿换矿脉，不能就地造假矿
4. **溢出吸收**：用户回答覆盖了下一问，直接吸收不重复问
5. 用户说嗨了跑题 → 跑题内容往往是真实素材，先记下来，再拉回主线

## 对话的双重身份：语料采集（P5 去 AI 味的原料）

三轮对话同时是**说话指纹采集**。用户自然状态下的表达就是最真实的语料，全程记录以下特征，三轮结束后提炼成指纹写入定位卡：

| 特征 | 观察什么 | 示例 |
|------|---------|------|
| 句长分布 | 长句多还是短句多？长短怎么交替？ | 「短句为主，偶尔一个长句一口气说完」 |
| 口头禅/黑话 | 高频出现的词、行业黑话、语气词 | 「根儿」「扯淡」「就这？」 |
| 断句习惯 | 一句话里在哪里换气、停顿 | 「逗号密，一逗到底倾向」 |
| 连接方式 | 怎么承接转折？书面词还是口语词？ | 「所以/然后/结果」而非「因此/综上」 |
| 情绪表达 | 怎么表达态度？直接判词还是绕弯？ | 「直接下判断：『这不是 X，是 Y』」 |
| 改口痕迹 | 会不会说一半换说法、自我纠正？ | 「有，『不对，应该这么说』——这是思维流指纹」 |

**提炼时机**：三轮问完、拆解输出之前。给用户看指纹提炼结果并确认（宪法第三条）——「这是我说话的样子吗？」用户认了才写入定位卡。

**漂移更新**：季度复核（与定位卡同步）时重采 10 分钟对话，比对旧指纹；漂移大则更新并注明变化原因（人/平台/阶段变化都会改变说话方式）。

**下游接口**：P5 写稿按此指纹落笔；IP官 把成稿与对话原话并排比对，用户从没用过的句式 = AI 代写痕迹，退回重写。

## 三轮标准问题（按主契约分化）

### 第一轮：观点（你的判断是什么）

| 契约 | 问法 |
|------|------|
| 确定感约 | 「这个事，你觉得最常见的错误做法是什么？为什么错？」 |
| 共鸣约 | 「这个话题，你自己最难受的时刻是什么感受？」 |
| 爽感约 | 「这个场面，你觉得最气人的点在哪？」 |
| 希望约 | 「回头看，你觉得转折点是哪一刻？」 |
| 优越约 | 「外行对这个事最大的误解是什么？」 |
| 新奇约 | 「知道了这个之后，你看哪儿的眼光变了？」 |

追问技巧：不接受形容词（「感觉挺好」→ 好在哪，具体到一件事）；不接受「大家都说」（→ 你自己怎么看）。

### 第二轮：亲身经历（高光挖掘轮）

标准问法：「这件事你有亲身经历吗？」

**按契约追问变体**（统一以本表为准，替代 contracts.md 旧「挖素材问法」字段）：
| 契约 | 经历轮追问 |
|------|-----------|
| 确定感约 | 「你踩过这个坑吗？最后怎么爬出来的？」 |
| 共鸣约 | 「那件事最具体的细节是什么？当时你心里第一反应是什么？」 |
| 爽感约 | 「你经历过最气的场面是什么？当时想说什么但没说出口？」 |
| 希望约 | 「你从什么状态爬起来的？最低点是什么样的？」 |
| 优越约 | 「这行里有什么外行根本不知道的事？」 |
| 新奇约 | 「你知道这事后，看世界的眼光变了吗？哪里变了？」 |

三类高光方向（对应高光素材库结构）：
- 做成过什么（希望约主素材）：起点多低、路径多具体、结果多真实
- 搞砸过什么（共鸣约/自曝素材）：当时的细节、代价、现在怎么看
- 逆转过什么（希望约/爽感约素材）：转折点在哪、谁/什么帮了你

**铁律**：用户说「没有相关经历」→ 不挂高光，靠结构和观点撑。缺就不挂，绝不编。
挖到新素材时问：「这个能存进你的高光库吗？」同意则入库。

细节追问：时间、地点、当时的心理活动、具体的某句话/某个动作——共鸣约的内容全靠这些细节。

### 第三轮：观众期望（你想让观众看完干嘛）

标准问法：「观众看完这条，你希望他做什么/变成什么样？」

- 校验与契约的一致性：签确定感约但用户想要转发 → 错配，提醒用户二选一
- CTA 转化链设计（仅一个营销动作）：
  - 合法：「关注我，下期拆 XX」（可兑现的具体承诺）
  - 非法：「关注我看更多」（空头支票）、「点赞收藏转发一键三连」（动作超过一个）

## AI 拆解输出（三轮完成后）

```
## 思路拆解（确认后进入结构设计）

核心观点：一句话（来自用户原话，尽量保留原句）
关键素材：列出挖到的经历/细节（标注来源轮次）
主契约：XX 约（从 A：___ 送到 B：___）
观众任务：看完做什么/变成什么
内容量预估：偏轻（≈Xs）/ 适中（≈Xs）/ 偏重（≈Xs，建议拆条）
存疑处：___（用户没说清的，标出来让用户补，不许默认填充）

——这个拆解对吗？哪里理解偏了？
```

**用户确认拆解无误后**，据内容量敲定时长（时长=输出不是输入），进 P4。

## 失效模式防御（写给 AI 自己）

| 失效 | 表现 | 防御 |
|------|------|------|
| 和气接受敷衍 | 用户答「都行/随便」就说好的继续 | 换个具体角度再问一次，再敷衍则换话题 |
| 提前结束 | 「差不多了」跳去写稿 | 三轮没齐不进拆解，缺哪轮补哪轮 |
| 默默填充 | 拆解里出现用户没说过的内容 | 只写用户说过的；推断标 [待确认] |
| 过度追问 | 一轮拆成五个问题 | 每轮最多 2 问，问完就停，等用户说完
