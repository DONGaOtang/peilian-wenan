# 信任引擎与感知雷达（结果侧参考文件）

> 信任 = 预期的反复兑现。爆款让人认识你，第十次兑现让人追你。
> 观众追的不是内容，是两部剧：你的人生连续剧 + 你的稳定供给栏目。

## 一、信任三阶段

### 0→1 借信任（冷启动）

| 杠杆 | 原理 | 动作 |
|------|------|------|
| 真干过 | 细节是真实的防伪码，编的东西没有细节 | 说一个只有干过的人才知道的细节，而不是「我做 X 十年」 |
| 敢自曝 | 暴露弱点 = 拆除防御 | 「我也踩过这个坑」比「我教你三招」可信十倍（高光库的「搞砸过」素材在这用）|
| 说到做到 | 冷启动期唯一能自己制造的信任事件 | 公开立一个小目标（如「下周拆解一个真实案例」），下期交作业 |

### 1→100 攒信任（放大）

- **主契约稳定兑现**：定位卡标的主契约不漂移。你是确定感供给者，就别突然发爽感约
- **稀缺性**：你的知识交叉组合（知识域档案里的独特组合），别人给不了
- **关键信任事件**：连载一个系列 / 公开做一件事让大家见证

### 锁定（信任红线）

**违约一次取光存款**：编造、卖假、背刺 = 信任账户清零，无恢复通道。
六官里的事实官就是这条红线的日常守门人。

## 二、追更双引擎

### 剧一：人生连续剧（叙事性追更）

观众在追「他上次说要干 X，现在怎么样了」。剧本格式：

```
## 连续剧目标卡（存 koubo-assets/ip-card.md 附录）

当前公开目标：___（具体、可验证、有期限）
立目标的那期：版本库 #N
进度线：
- [ ] 阶段一：___（对应某期视频）
- [ ] 阶段二：___
- [ ] 结果复盘：___（无论成败都交作业——失败复盘的信任收益往往更高）
```

- 每完成一阶段发一期进度视频（高光库+版本库自动提供素材）
- 失败了照实说：这是「敢自曝」杠杆的复用，也是真诚履约

### 剧二：稳定供给剧（供给性追更）

观众形成「到点来领」的条件反射。设计：
- IP 定位卡 = 节目单：主契约类型 + 固定栏目名 + 更新节奏
- 栏目化命名（如「每周拆一个真实案例」），标题带栏目前缀
- 断更超过承诺节奏 = 供给违约，宁可降频也别断（提前说明除外）

## 三、感知雷达（「时刻敏感」的工程化）

不是时刻盯，是**固定节律 + 触发式扫描**。

| 级别 | 信号源 | 节律 | 动作 |
|------|--------|------|------|
| 一级（最真实）| 自己视频的评论区+私信 | **由 P6 回流执行**：48-72h 首轮深扫 + 第 7 天终轮复查长尾 | 履约密码逐条归档（contracts.md 对照表）——本行与 P6 是同一件事，**不重复执行** |
| 二级（半真实）| 对标账号评论区 + 赛道关键词漂移 | 每周轻扫 | 对标新爆款入库 + 下拉词周对比 |
| 三级（滞后参考）| 热榜、平台官方趋势 | 选题时按需扫 | 只当参考不当圣旨 |

### 漂移报告模板（每次扫描后产出，喂下一圈 P2）

```
## 观众需求漂移报告（日期）

评论区新高频词：___（上周没有的）
情绪风向变化：___（如：从「怎么学」变「值不值得学」→ 焦虑加深）
对标新打法：___（哪个对标号的新爆款，结构上变了什么）
对选题的启示：___（1-3 个方向提示）
置信度：高/中/低（样本量：N 条评论）
```

### 感知红线

- 观众的欲望写在评论区，不写在热榜上
- AI 情绪判断滞后于梗和风向的半衰期——以实时评论语言为准，模型直觉只做初筛
- 涨粉与看热闹分开统计：看热闹不涨粉的内容在消耗 IP（IP 资产视角的 P6 铁律）
