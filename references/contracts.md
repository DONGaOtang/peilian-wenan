# 六种情绪契约（观众层核心文件）

> 第一性原理：观众刷到的不是内容，是一次情绪状态的迁移。内容只是迁移的载具。
> 每个观众点开视频时处在状态 A，实际在等的是被送到状态 B。承诺了没完成 = 契约违约 = 划走/取关。

## 识别方法（观众不会告诉你他要什么，只能读）

1. **话题携带的情绪信号**（冷启动用）：
   - 副业/搞钱/技能话题 → 焦虑+希望（确定感约或希望约）
   - 职场吐槽/甲方话题 → 压抑（爽感约或共鸣约）
   - 行业内幕/避坑 → 不安（优越约）
   - 跨界冷知识 → 无聊（新奇约）
2. **评论区语言**（校准用，最真实）：
   - 「太真实了」「我就是」 → 共鸣约受众
   - 「收藏了」「学到了」 → 确定感约受众
   - 「关注了跟着学」 → 希望约受众
   - 转发@好友 → 爽感约受众
   - 「就这？」「标题党」 → 契约违约信号
3. **下拉联想词颗粒度**：搜痛点词看延展词——「XX 怎么解决」是确定感需求，「XX 是不是没救了」是共鸣需求。

**规则**：一条视频只签一种主契约，最多一种辅契约。签约类型必须写进 P4 的结构设计参数。

## 契约一：确定感约

- **迁移**：焦虑「我做不对」 → 安心「我知道怎么做了」
- **形态**：干货 / 清单 / 方法论 / 教程
- **服务要点**：结论明确、步骤可执行、必须给「现在就能做的一小步」
- **钩子写法**：痛点场景 + 承诺具体结果（「三步，让你的 XX 不再 XX」）
- **履约密码**：收藏率高
- **翻车点**：收藏了不行动 = 假确定。对策：结尾给一个 60 秒内能完成的最小动作
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约二：共鸣约

- **迁移**：孤独「只有我这样」 → 被理解「原来大家都这样」
- **形态**：真实经历 / 吐槽 / 自我暴露
- **服务要点**：细节真实到像偷窥了观众的生活。**细节必须来自用户亲口说的经历（宪法第二条），AI 编的细节没有指纹**
- **钩子写法**：具体场景 + 时间 + 心理活动（「凌晨两点，我盯着退货页面，不敢点确认」）
- **履约密码**：「太真实了」「我也是」
- **翻车点**：细节模糊、强行升华。共鸣内容禁止金句结尾
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约三：爽感约

- **迁移**：压抑「受气了没法发作」 → 释放「替我赢了/骂了」
- **形态**：冲突升级 / 反转打脸 / 替观众出头
- **服务要点**：彻底的胜利或惩罚结局，不能半途和解
- **钩子写法**：直接进入冲突现场（对话或动作开头）
- **履约密码**：转发 + @好友
- **翻车点**：尺度失控、树敌、拉踩具体的人。**慎用：涨流量快，但不积累 IP 信任**
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约四：希望约

- **迁移**：迷茫「我烂透了没出路」 → 有方向「他行我也行」
- **形态**：逆袭故事 / 可能性展示 / 高光复盘
- **服务要点**：起点要低（跟我一样烂）+ 路径要具体（怎么走的我告诉你）。缺一样就是鸡汤
- **钩子写法**：晒结果 + 反转（「我做成了 X，最反直觉的是 Y」）
- **履约密码**：「关注了跟着学」
- **翻车点**：假希望（路径不可复制）会被评论区拆穿反噬
- **高光库接口**：这是高光素材库的主战场。「做成过什么」的故事都在这签
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约五：优越约

- **迁移**：不安「我怕被坑」 → 掌控「我比你懂」
- **形态**：揭秘 / 避坑 / 内幕 / 行业黑话翻译
- **服务要点**：「他们不会告诉你」的信息差姿态。一个具体细节胜过三个形容词
- **钩子写法**：反常识断言（「你以为的 X，其实是 Y」）
- **履约密码**：评论区站队、讨论
- **翻车点**：民科化、阴谋论化、无依据断言
- **交叉检索接口**：跨域信息差是主战场（用心理学讲职场、用供应链讲砍价）
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约六：新奇约

- **迁移**：无聊「又是一样的」 → 大开眼界「还能这样」
- **形态**：冷知识 / 跨界交叉 / 认知反转
- **服务要点**：「你以为的 X 错了」认知反差，前后对比要具体
- **钩子写法**：直接抛反差（「这个每天用的东西，设计初衷是 X」）
- **履约密码**：完播率显著高于账号均值（≥ 均值 + 5pp），或评论出现「还能这样/长见识/学到了冷知识」
- **P6 履约判定**：两者都无 = 未履约（猎奇未积累）
- **翻车点**：猎奇无积累，爽完就忘。对策：结尾挂一个「为什么你需要知道这个」
- **交叉检索接口**：知识域交叉的天然出口
- **P3 挖素材问法**：见 dialogue-guide.md 第二轮「按契约追问变体」（经历轮）

## 契约判别表（分类可靠性地基——低置信度回问用户）

| 契约 | 必须存在 | 互斥判据（有则不选此约） |
|------|---------|------------------------|
| 确定感约 | 可执行步骤/结论 | 无步骤只有故事 → 不是确定感 |
| 共鸣约 | 具体细节+情绪在场 | 有「冲突对象/敌人」→ 偏爽感；有「信息差」→ 偏优越 |
| 爽感约 | 冲突对象+彻底结局 | 有「教你方法」成分 → 转确定感 |
| 希望约 | 低起点+具体路径 | 路径不可复述 → 假希望，砍 |
| 优越约 | 信息差+「他们不会告诉你」姿态 | 有「认知反差但无信息差」→ 转新奇 |
| 新奇约 | 认知反差+解释 | 有「防坑/内幕」实用指向 → 转优越 |

**判别流程**：AI 按上表判主契约 → 若两契约都成立 → 标注双候选+置信度 → 问用户「这条你更想让观众____（学到方法/被理解/爽到/看到希望/觉得你懂/大开眼界）」→ 用户选的主契约写入 P4 结构设计参数。

## 反滥用红线

- 可以唤起状态 A（焦虑/孤独/压抑），**必须真实送达状态 B**。只唤起不送达 = 情绪勒索 = 消耗 IP 资产
- 契约不能背刺人设：IP 定位卡标注主契约类型，爽感约是兴奋剂，不作为主契约
- AI 判情绪会滞后：契约识别以评论区实时语言为准，模型直觉只做初筛
