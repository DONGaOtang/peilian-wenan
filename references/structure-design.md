# 结构设计（P4 参考文件）

> 节奏是事前设计，不是事后检查。验尸做得再细，救不了先天心律不齐。

## 时长原则（铁律）

**时长 = 输出不是输入。**由 P3 拆解出的内容密度决定：30 秒讲得透就 30 秒，5 分钟才够就 5 分钟。禁止任何默认时长、禁止「抖音都是 XX 秒」的从众设定。
（对照记忆：知识/方法论类内容通常 2-3 分钟才讲得透——但这是参考不是约束。）

## 节拍参数（适用于任何时长）

| 检查点 | 标准 | 心理机制（通俗类比，非严谨科学机制）|
|--------|------|---------|
| **前 3 秒** | 钩子成立：拦得住拇指，承诺了契约的 B 状态（官方数据：流失从第 1-2 秒开始；行业口径「黄金3秒」） | 注意定向/新颖性（陌生信号拦拇指）——信息缺口是「第二棒」 |
| **5s** | 第一个信息刷新：观众确认「继续看有好处」 | open loop（未闭合回路）+ 预期后悔；「不看完亏什么」是损失框架文案，不是观众天然机制 |
| 每 **8-20s 弹性** | 信息刷新点：由内容密度决定，不是固定节拍。逐段自问「这段提供了什么上一段没有的信息？」，答不出=该段该删。**禁止机械按 15-20s 切点**（3 分钟以上视频尤其） | 预期违背 + 惊讶 + 好奇（「你以为的 X 是错的」）|
| 结尾 | 埋未完成感（下期预告/系列钩）或给最小行动 | 未完成感（need for closure）驱动的追更预期；蔡格尼克效应为通俗类比（其本身是记忆现象非追更动机）|

**空帧检查**（借鉴 video-spec-builder 信息密度铁律）：任何一段 ≥4 秒的内容必须能回答「这 4 秒在表达什么」，答不出就砍。

## 六契约的情绪曲线形状

| 契约 | 曲线 | 关键拍 |
|------|------|--------|
| 确定感约 | 焦虑唤起 → 阶梯下降到安心 | 开头痛点场景（唤 A）→ 每步降一档焦虑 → 结尾最小动作（送 B）|
| 共鸣约 | 平淡开场 → 骤然扎心 → 陪感收尾 | 具体场景（细节！）→「我也是」时刻 → 不升华，停在情绪里 |
| 爽感约 | 压抑蓄势 → 直线拉满 | 冲突现场直入 → 层层升级 → 彻底的胜利/惩罚结局 |
| 希望约 | 低谷共鸣 → 爬升 → 具体路径 | 起点LOW（跟我一样烂）→ 转折点 → 路径具体到可执行 |
| 优越约 | 不安唤起 → 反常识断言 → 掌控感交付 | 「你以为的 X 错了」→ 内幕细节 → 「现在你知道怎么防了」|
| 新奇约 | 认知反差 → 解释 → 世界观微调 | 直接抛反差 → 为什么 → 「从此你看 X 的眼光变了」|

## 封面与标题（图文侧第一钩子，独立设计）

- **封面三问**：远看（缩略图）看得清主信息吗？主信息是承诺 B 状态吗？和同赛道封面有区分度吗？
- **标题公式**（按契约）：
  - 确定感约：痛点 + 具体结果（「别再 XX 了，三步搞定」）
  - 共鸣约：具体场景 + 时间（「凌晨两点，我 ___」）
  - 希望约：结果反转（「我做成了 X，最反直觉的是 Y」）
  - 优越约：反常识（「你以为的 X，其实是 Y」）
  - 爽感约：冲突前置（「别忍了，这口气我替你出」）
  - 新奇约：反差前置（「用了十年的东西，设计初衷是 X」）
- 用户自体样本辅助：三个方案自己扫一眼，哪个让你想点——只做初筛，不当终审

## 附录：平台指标替换表（非抖音平台使用本系统前必读）

本系统判据（2s 跳出/完播率/5s 数据）为抖音创作者后台口径。各平台指标对照：

| 平台 | 可用指标 | 与抖音口径差异 | 本系统判据的换算建议 |
|------|---------|--------------|--------------------|
| 抖音 | 完播率、平均播放时长、3秒/5秒完播率、逐秒留存曲线（「2s跳出」是运营解读，非官方命名指标） | 基准 | 直接用 |
| 视频号 | 完播率、平均播放时长、点赞/分享/评论 | 口径最接近抖音，无秒级跳出 | 用完播率+平均播放时长替代 2s/5s 判据 |
| 小红书 | 浏览、赞藏评、互动率、收藏率、涨粉 | 视频笔记有完播数据，主流重互动与收藏 | 钩子判据改用「前 3 秒互动率」；履约密码以收藏/互动为准 |
| B 站 | 播放、投币、收藏、转发、弹幕、评论 | 长视频平台，完播含义不同，讲究「播放完成率」 | 钩子判据改用「3 分钟完播/防跳P」；系列钩适配追番式观看 |

**红线**：任何平台都**不存在**「2 秒跳出率」官方指标；本系统所称 2s 跳出一律指后台逐秒留存曲线的解读。

## 结构官禁项

- 金句结尾、人生道理式收尾：禁（陈词滥调，观众看到金句铺垫就开始划）
- 自问自答连续两次以上：禁
- 「大家好/今天给大家介绍」开场：禁（口语官死刑标准，结构上也不许）
- 悬念空头支票（钩子承诺了但正文不兑现）：禁（契约违约）
