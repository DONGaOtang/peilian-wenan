# 发布执行与运营清单（P2 增强参考文件）

> 本文件补齐执行层与运营层：P5 成稿之后、发布之前/之后的关键动作。

## 一、发布执行清单（P5 终审通过后）

1. **发布时间窗**：主赛道流量高峰（口播/知识类通常 11:30-13:00、17:30-19:00、21:00-22:30；以对标库的实际数据为准，不要拍脑袋）
2. **封面制作**：按 P4 封面三问执行（远看清晰 / 主信息=承诺 B 状态 / 有区分度），三个方案选一后制作
3. **标题 A/B**：同内容备两版标题，先发 A 版，24h 后数据明显差则换 B 版（图文平台第一钩子）
4. **发布前自检**：封面 + 标题 + 正文首句，三个「钩子」必须指向同一个 B 状态（防钩子货不对板）
5. **发布后 1 小时**：评论区引导（见下）

## 二、评论区运营 SOP（一级信号主来源：被动读改为主动经营）

- **置顶引导评论**：发布时置顶一条「契约密码」引导（确定感约→「你踩过这个坑吗」；共鸣约→「你也有过这个瞬间吗」）——让一级信号更密
- **回复节奏**：前 48h 回复所有带情绪评论（情绪是信号；回复同时是互动率和信任事件）
- **实时归档**：带契约密码的评论按 contracts.md 对照表实时进 P6 素材，不等 48h 一起抄
- **违约信号处理**：「就这/标题党」类评论不删不怼，记录进 P6 归因（违约也是数据）

## 三、变现路径设计（与主契约匹配，一条视频一个营销动作）

| 主契约 | 适配变现 | 说明 |
|--------|---------|------|
| 确定感约 | 课程/咨询/工具 | 方法交付的天然买家 |
| 希望约 | 社群陪跑/训练营 | 「他行我也行」→ 我带你也行 |
| 共鸣约 | 私域/陪伴型产品 | 信任深但变现慢，先经营关系 |
| 爽感约 | 带货引流（慎用） | 涨流量快但不积累信任，不挂主契约 |
| 优越约 | 高客单咨询/圈层服务 | 「我比你懂」→ 付费买懂 |
| 新奇约 | 知识付费的钩子 | 猎奇不直接变现，导流到确定感内容 |

## 四、合规红线自查表（并入事实官，发布前逐项过）

- [ ] 无医疗/健康功效断言（不得说「治好」「根治」）
- [ ] 无金融收益承诺（不得说「稳赚」「保本」）
- [ ] 无夸大宣传（「全网第一」「绝对」「100%」类绝对化用语）
- [ ] 数据/案例可查证，宣称可被证伪
- [ ] 不拉踩具体品牌/个人（爽感约尤需注意）

## 五、心理安全红线

- **自曝素材强度分级**：1 级（无害糗事）/ 2 级（痛点但可说）/ 3 级（隐私/创伤）
- **自曝上限**：P0 初始化时问一次用户能接受的最高级别，写入定位卡
- **宪法第五条**：不逼问用户不愿讲的事——用户回避的话题一次问过即止，不追问、不诱导
