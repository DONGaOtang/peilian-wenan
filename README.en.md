## 🚀 30-Second Intro for Beginners

- **What it is**: An AI coaching system that walks you through making "talking-head" short videos. You talk, AI structures; you stay silent, AI writes nothing.
- **The problem it solves**: You want to make talking-head videos but don't know what to say, drafts come out with a heavy "AI smell", or you hit one viral video and can't replicate it.
- **How to use**: Drop this folder into your AI assistant's skills directory (Claude Code / Codex, etc.), then say "help me make a talking-head video".
- **Time to first result**: ~10 minutes for first-time setup (AI helps you build 5 asset libraries); after that, every video runs through the full loop: topic → material → structure → draft → publish → review.

**In one line**: Turn "viral by luck" into "viral by system" — every video makes the system know you better and keeps your audience coming back.

## What This Is

Wenan Peilian is a **spoken-word IP content asset system** that breaks one talking-head video into 6 phases (P0-P6) and accumulates 5 asset libraries:

- **Account Diagnosis**: Figure out who you are and what you're trying to push forward before making content
- **Six Emotional Contracts**: Each video signs exactly one "emotional contract" (Certainty / Resonance / Catharsis / Hope / Superiority / Novelty), promising to move the viewer from state A to state B
- **Seven-Judge Review**: After drafting, 7 "judges" attack the script along 7 axes — Facts, Rhythm, Logic, Contract, Spoken-language, IP, Structure. Issues must be fixed, not just flagged
- **Data Reflux**: First review at 48-72h + final review on day 7, turning data into ammunition for the next topic
- **Asset Compounding**: Highlight materials, speaking fingerprint, benchmark teardowns, version data — all accumulated, thicker every month

**Core stance**: Material must come from your real, first-person experience; AI asks, deconstructs, arranges, quality-checks, and records — the muscle is always yours.

## Quick Start

### 1. Install

Place the whole folder (with `SKILL.md` and `references/`) into your agent's skills directory:

| Platform | Directory |
|----------|-----------|
| Claude Code | `~/.claude/skills/wenan-peilian/` |
| Codex | `~/.codex/skills/wenan-peilian/` |
| Generic Agents | `~/.agents/skills/wenan-peilian/` |

### 2. Trigger

Say any of these to your AI:

- "Help me make a talking-head video"
- "Produce a video"
- "Run the pipeline"
- Or type `/dong-pl` (also `/peilian` / `/wenan-peilian`)

### 3. First run (P0 Account Diagnosis, ~10 min)

The AI walks you through 4 steps:

1. Answer one question: "What's the one thing you most want to push forward right now?"
2. Copy 3-5 videos' metrics from your account dashboard (completion rate / 2s bounce / engagement)
3. Build 5 asset libraries (`koubo-assets/`): IP Card, Highlights, Knowledge Domains, Version History, Benchmarks
4. Confirm your "speaking fingerprint" (the AI will mimic your tone when writing — not an AI voice)

### 4. Daily loop (per video)

```
P2 topic generation → P3 dialogue mining → P4 structure design → P5 draft + seven-judge review → publish → P6 data reflux
```

All you need to do: reply with an index to pick a topic, tell your own stories, read the draft aloud once, and copy 5 numbers after publishing. **Every input is one-sentence level — if it takes more than a minute, coaching becomes homework.**

### 5. Platform scope

The data metrics in this system (2s bounce / completion rate / 5s data) use the **Douyin creator dashboard** standard. For Xiaohongshu / WeChat Channels / Bilibili, convert per the *Platform Metrics Mapping Table* appendix in `references/structure-design.md`.

## Architecture (Four Layers, One Loop)

| Layer | Content |
|-------|---------|
| Audience Layer | Six emotional contracts — viewers don't consume content, they experience a state transition |
| Asset Layer | 5 libraries + judge-weight ledger — your materials + your intersections + your data are a moat nobody can copy |
| Process Layer | P0 diagnosis → P1 direction → P2 topic → P3 mining → P4 structure → P5 draft → P6 reflux |
| Mechanism Layer | Psychology parameters / beat design / cross-domain retrieval / seven-judge panel (incl. logic judge) |

**Result-side trio**: Viral formula (push the four controllable factors + hedge luck), trust engine (trust = promises repeatedly kept), perception radar (3-tier signals: comments / benchmarks / trends).
