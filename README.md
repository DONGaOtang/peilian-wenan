## 🚀 小白 30 秒读懂

- **这是什么**：一套陪你做「口播短视频」的 AI 陪练系统。你说，AI 帮你拆；你不说，AI 不写。
- **解决什么问题**：想做口播视频但不知道讲什么、写出来一股 AI 味、火了一条就没了后劲。
- **怎么用**：把本文件夹放进你的 AI 助手（Claude Code / Codex 等）的 skills 目录，然后说一句「帮我做一条口播」。
- **多久见效**：首次初始化约 10 分钟（AI 带你建 5 个资产库）；之后每产一条视频，AI 陪你走完「选题 → 挖素材 → 结构 → 成稿 → 发布 → 复盘」全流程，越用越懂你。

**一句话**：把「爆款靠运气」变成「爆款靠系统」——每产一条，系统更懂你，观众更离不开你。

## 这是什么

文案陪练是一套 **口播 IP 内容资产系统**，把一条口播视频从选题到发布回流的全程拆成 6 个阶段（P0-P6），并沉淀成 5 个资产库：

- **账号底诊**：先搞清楚你是谁、想推进什么，再谈做内容
- **六种情绪契约**：每条视频只签一种「情绪合同」（确定感/共鸣/爽感/希望/优越/新奇），承诺把观众从状态 A 送到状态 B
- **七官自检**：成稿后由 7 个「评审官」从事实、节奏、逻辑、契约、口语、人设、结构 7 个轴挑毛病，改不止标
- **数据回流**：发布 48-72h 首轮复盘 + 第 7 天终轮，把数据变成下一圈的选题弹药
- **资产复利**：高光素材、说话指纹、对标拆解、版本数据全部沉淀，越用越厚

**核心立场**：素材必须来自你亲口说的真实经历；AI 负责提问、拆解、排布、质检、记录——肌肉长在你身上。

## 快速开始（使用说明）

### 1. 安装

把整个文件夹（含 `SKILL.md` 和 `references/`）放到你的 Agent skills 目录：

| 平台 | 目录 |
|------|------|
| Claude Code | `~/.claude/skills/wenan-peilian/` |
| Codex | `~/.codex/skills/wenan-peilian/` |
| 通用 Agents | `~/.agents/skills/wenan-peilian/` |

### 2. 触发

对 AI 说任意一句：

- 「帮我做一条口播」
- 「产一条视频」
- 「跑一遍产线」
- 「陪练」
- 或直接输入 `/陪练`、`/dong-pl`

### 3. 首次运行（P0 账号底诊，约 10 分钟）

AI 会引导你做 4 件事：

1. 回答一个问题：「你现在最想推进的一件事是什么？」
2. 从你的账号后台抄 3-5 条视频数据（完播率 / 2s 跳出 / 互动数）
3. 建 5 个资产库（`koubo-assets/` 目录）：IP 定位卡、高光素材库、知识域档案、脚本版本库、对标库
4. 确认你的「说话指纹」（AI 之后写稿时模仿你的口吻，而不是 AI 腔）

### 4. 日常循环（每产一条视频）

```
P2 话题生成 → P3 对话挖素材 → P4 结构设计 → P5 成稿+七官自检 → 发布 → P6 数据回流
```

全程你只需要：回编号挑选题、说自己的经历、出声读一遍稿、发布后抄 5 个数字。**每个输入都是一句话级别，超过一分钟就变成作业了。**

### 5. 平台口径

本系统数据指标（2s 跳出 / 完播率 / 5s 数据）为 **抖音创作者后台** 口径；小红书 / 视频号 / B 站需按 `references/structure-design.md` 附录《平台指标替换表》换算。

## 系统架构（四层一循环）

| 层 | 内容 |
|----|------|
| 观众层 | 六种情绪契约（确定感/共鸣/爽感/希望/优越/新奇）——观众刷到的不是内容，是状态迁移 |
| 资产层 | 五库 + 七官权重台账——你的素材+你的交叉+你的数据，是别人抄不走的护城河 |
| 流程层 | P0 底诊 → P1 方向 → P2 选题 → P3 挖素材 → P4 结构 → P5 成稿 → P6 回流 |
| 机制层 | 心理学参数化 / 节拍设计 / 交叉检索 / 七官面板（含逻辑官） |

**结果侧三件套**：爆款公式（可控四项推满+运气对冲）、信任引擎（预期的反复兑现）、感知雷达（评论区/对标/热榜三级信号）。
